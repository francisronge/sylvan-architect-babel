# Babel Visual Relations: Exhaustive Working Inventory

Status: historical exhaustive research inventory. The active Babel roadmap is
limited to the 35 directly authorable (`D`) fixtures and two Replay-derived
(`R`) fixtures. The 25 excluded (`Q`) contract-gap studies are retained only as
historical evidence; they are not planned Lab work.

## Purpose

Babel's ontology is open. The model may name a relation that no renderer author predicted. The lab therefore cannot stop after a short list of familiar English GB/Minimalist phenomena. It needs:

1. an exhaustive inventory of attested non-branching syntactic and interface relations;
2. a finite set of reusable visual grammars that can render those relations without closing the ontology;
3. stress fixtures proving each grammar across difficult anchor topologies; and
4. an explicit account of relations the current node-only contract cannot faithfully witness.

The Cambridge Handbook of Generative Syntax supplies the broad module checklist: argument structure, predication, projection/cartography, binding, raising/control, agreement/Case, locality, ellipsis, TAM, negation/polarity, scope, and information structure/prosody. This inventory also audits Minimalism, GB, Distributed Morphology, LFG/HPSG/TAG/CCG-style dependencies, typologically broad morphosyntax, and signed-language externalization.

## Active Babel Scope

The Lab researches only relations Babel can express through the current
contract: open relation names and roles anchored to current-stage syntax nodes,
plus renderer-derived geometry and Replay-derived comparisons.

The active roadmap excludes:

- syntax-prosody tiers, intervals, or correspondence planes;
- signed-language loci, articulator tiers, spatial vectors, and external
  speaker/addressee anchors;
- AVMs, full f-structures, autonomous semantic/prosodic projections, and other
  framework-native objects that are not Babel syntax nodes;
- any other proposed drawing whose required endpoints cannot be authored by
  the current Babel relation contract.

The `BLOCKED` rows and `Q` fixtures below remain historical research records.
They must not be counted as remaining work, placed in a future quarantine lane,
or revived without an explicit contract-scope decision from Francis.

## Admission Rule

A candidate is retained only when all of the following hold:

- It relates two or more objects, a node to a region/state, or a syntactic object to an interface realization.
- Ordinary mother-daughter or sisterhood geometry does not already express the entire claim.
- Babel's generated replay microsteps do not already express the entire claim.
- Syntacticians have an attested tree-attached convention for it: indices, paths, feature marks, regions, boundaries, pronunciation state, correspondence tiers, or an equivalent mark on a real syntax/LF tree.
- The mark records analysis, not decoration or an exercise answer.

Rejected evidence includes ordinary trees, prose slides, brackets detached from a tree, semantic formulas detached from syntax, waveforms, spectrograms, and diagrams that merely name an adjacent topic.

## What Does Not Count

Do not add a visual relation for:

- External Merge, projection, endocentricity, ordinary selection, head-complement/specifier geometry, ordinary adjunction, dominance, c-command, or sisterhood when the tree already shows them.
- A construction name when its analysis reduces to an existing relation: passive/raising/topicalization/scrambling are not new geometries merely because their names differ.
- A constraint name when the visual claim is only a judgment about already visible geometry.
- Final surface order by itself. The leaf order already shows it.
- Silent `PRO`, `pro`, traces, null operators, or other authored terminals by themselves. Their licensing, identity, deletion, or dependency may still require a relation.

### Named Exclusion Ledger

These were explicitly considered. They do not receive independent visual grammars unless a particular analysis adds one of the retained non-branching relations:

- External Merge, projection, endocentricity, X-bar levels, Bare Phrase Structure, head/complement/specifier, ordinary adjunction, selection, dominance, sisterhood, c-command, m-command, government, and ordinary cartographic projection.
- Raising, passive, unaccusative movement, topicalization, scrambling, object shift, clitic climbing, incorporation, and possessor raising as construction names. Their analyses dispatch to trajectory, identity, Agree/Case, PF, or domain grammars.
- Empty-category type, `PRO`, `pro`, trace, variable, null operator, and null head as authored nodes. Only identity/licensing/deletion/dependency is additional.
- Projection Principle, Extended Projection Principle as a global principle, UTAH, Theta Criterion, Case Filter, Visibility Condition, Chain Condition, Proper Binding Condition, Bijection Principle, Minimal Distance Principle, PRO theorem, I-within-i, A-over-A, and other well-formedness conditions when they only validate existing structure. A sourced failure witness may use the diagnostic grammar.
- That-trace/COMP-trace, Doubly Filled COMP, nominative island, and local occupancy violations when the offending configuration is fully visible in the authored tree. A judgment/diagnostic is separate metadata.
- Plain NegP/PolP, ordinary semantic scope, ordinary weak-NPI licensing by dominance/downward entailment, ordinary topic-comment structure, covert `Exh` as a node, and detached lambda-calculus/DRT/MRS/Glue/continuation formulas.
- Applicative, causative, classifier, light-verb, serial-verb, restructuring, and event-decomposition structures when the source convention is ordinary branching plus node labels. Their non-branching role sharing, movement, feature, or function mapping remains retained.
- Default LCA precedence, final leaf order, and a separate surface rail that merely repeats the sentence. Only analytically asserted adjacency, cyclic order, rebracketing, or order conflict is retained.
- Full f-structures, AVMs, semantic graphs, prosodic trees, waveforms, spectrograms, timelines, and gestural demonstrations detached from a syntax-tree correspondence. Native framework machinery is retained only where its relation to syntax is explicit.

## Stop Condition

There is no credible universal finite list of every term a future paper or model may invent. For the active, Babel-expressible scope, there is a defensible finite stopping condition:

1. Every retained named relation below maps to an attested visual grammar.
2. Every in-scope visual grammar is implemented and has at least one valid
   Babel fixture.
3. Every distinct anchor topology has a stress fixture: unary, binary, ordered chain, fan-in, fan-out, many-to-many, region/boundary, path interaction, state transition, and cross-tier span.
4. Every active fixture uses only current-stage node IDs as authored anchors,
   or is explicitly derived by comparing Replay stages.
5. Two independent adversarial audits find no unmapped in-scope relation
   topology and no retained tree-only false positive.

That is the stopping rule. A raw HTML-card count is not.

## Live Babel Reality

The live contract is an open relation plus open role names whose values are same-stage node IDs or arrays of node IDs. It can author arbitrary current-stage node hyperedges. It cannot directly anchor:

- a scalar index such as `i`;
- a chain name;
- a tree edge, path, region boundary, or relation instance;
- an earlier-stage-only object;
- an external speaker, addressee, NOW, spatial locus, prosodic interval, PF exponent, or LF object unless that object is authored as a syntax node.

The correction pass removed all scalar `chain` and `index` pseudo-anchors from the lab. Chain identity now comes from anchored occurrences and their `lineageId`; display indices are assigned deterministically by renderer logic. Production still renders trajectory-compatible relations only, so "present in the lab" does not mean "implemented in Babel." Endpoints listed above as unavailable are scope boundaries, not a future implementation backlog.

## Formal Coverage Basis

All finite overlays can be described with nine topological constructors. These are a completeness test, not a claim that nine visual styles are enough.

| Constructor | Covers |
| --- | --- |
| Global judgment | whole-analysis convergence, `*`, `?`, violation |
| Unary predicate | feature, accessibility, pronunciation/deletion, prominence |
| Role-labelled hyperedge | binary and n-ary dependencies, fan-in/fan-out |
| Order/successor | chains, precedence, accumulation, derivational order |
| Equivalence/conflict | copies, coindexation, disjointness, overlap, inconsistency |
| Incidence/containment | domains, regions, boundaries, path entry/exit |
| Typed correspondence | syntax-PF/LF/prosody maps, one-to-many and many-to-one |
| State transition | valuation, Transfer, deletion, insertion, realization |
| Higher-order relation | intervention, path crossing/nesting, blocking, feeding/bleeding |
