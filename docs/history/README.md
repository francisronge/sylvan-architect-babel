# Babel History

These files preserve the July 2026 architecture packet and the renderer
closeout's audit ledger and reviews. They are non-authoritative records, not
instructions for current work.

Remaining work lives only in [`ROADMAP.md`](../../ROADMAP.md). Older plans,
device handoffs and dated reports were removed; Git history keeps them.

Historical does not mean disposable. In particular, the
[Fable Zero Unknowns packet](architecture/fable-zero-unknowns-2026-07-17/README.md)
is the detailed architecture rationale behind several active roadmap programs.
Its old repository anchors and rollout commands are obsolete; its reconciled
product, benchmark, renderer, and durable-record decisions remain required
context.
